F鯖(フレーム鯖)について

約2000人規模のアークナイツ Discordサーバーです。高速周回の情報共有を中心に、初心者支援や雑談、各種計算ツールの提供も行っています。

Discordに参加する

アステシアちゃんについて

F鯖での日々を穏やかに支える案内役botです。オペレーターの誕生日アナウンスや各種計算機能の提供、サーバー環境の維持など、さまざまな役割を担っています。

GitHubで見る

アークナイツ

  • 公開求人ショートカット iOSからワンクリックで公開求人検索
  • 理性タイマーショートカット iOSで理性満タンになる瞬間をお知らせ
  • フレームキル計算機 スキルダメージが敵を撃破できるか計算
  • 理性効率APIスキル（Claude用） 理性効率・理性価値をClaudeが直接引けるスキルをダウンロード

エンドフィールド

  • 武陵発電計算機 武陵ステージの発電制御を最適化
  • ENDFIELDレシピ計算機 エンドフィールドの資材レシピを計算

他の趣味ツール

  • 幽霊船宝箱ソルバー レジェンド オブ ドラグーンの幽霊船宝箱を解く
  • 試験手順ランナー 試験手順書をチェックリスト形式で進行
  • ClawdなでなでMod Claude Codeでお仕事中になでなで
